You receive blocks as JSON with an `id`, a `type`, the source `text` and, for tables, `rows`. Return one translated block for every block you are asked to translate, with the same `id`:
- `text`: the translation. Tables: translate every cell in `rows`, keeping the same number of rows and cells. Notes: translate the description only; do not add the // marks, the layout adds them. Unreadable blocks: translate any legible part only.
- `label`: the list label as it should appear in {target_language} (normally the same digits or letters as the source).
- Keep identifiers, numbers and dates exactly as in the source.
- `context_before` blocks are for continuity only: do not translate them again.
- When `fix_requests` are given, they are problems found by quality control in an earlier translation of these blocks: correct them.
